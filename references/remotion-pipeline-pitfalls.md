# Remotion / FFmpeg / ASR 管线踩坑

每条写成“现象 → 规则”，附观测来源。「观测实例」来自冈仁波齐转山 vlog，只作观测，不作定律。
[`screen-studio-remotion-qc.md`](screen-studio-remotion-qc.md) 与 [`series-template.md`](series-template.md)
已记的坑不重复，只在相关处互相指路。

## Remotion Studio

- 交 Studio 链接前，先确认开发服务器在跑、页面加载的是本轮数据：总时长、某个新章节或字卡、音频文件的
  字节数和时长都要对得上；不能只跑完同步脚本就说“已刷新”。会话重启或恢复后第一件事是确认服务还在
  （观测实例：作者两次遇到 ERR_CONNECTION_REFUSED，一次交付前发现服务已停）。刷新后的实播与控制台检查
  见 screen-studio-remotion-qc「Studio 分阶段检查矩阵」。
- 作者说 Studio “没同步”时，先查组件最外层有没有被写入 `from=` 偏移：在 Studio 时间轴上拖动最外层轨道，
  Studio 会把位移写回代码（观测实例：`from={-818}` 让画面、字幕、音频整体偏了约 27 秒），再查数据。
  提醒作者点上方刻度跳转，不要拖轨道。
- 预览音频作为实体文件放进 `public`（从最终混音 stream copy 或转成 AAC 的 m4a），不用软链接：相对和绝对
  软链接在渲染时都会 404，镜头目录的软链接却正常。最终渲染与封装仍用原始 WAV 混音。
- 秒换算成帧时，每段起点和终点都用绝对时间各自取整一次，不逐段累加浮点再取整；生成后检查同一轨道没有
  重叠帧或空隙帧（观测实例：累加取整让一段视频与后面的黑场重叠 1 帧）。与 series-template「EDL 段之间
  不许有重叠帧」同源。
- 编译阶段丢弃或合并不足一帧的片段，并断言所有 Sequence 的 `durationInFrames ≥ 1`；不要等 Studio 报
  `durationInFrames must be positive`（观测实例：一段口播比照片早 0.02 秒开始，取整后成了 0 帧）。
  片头片尾整段关掉时也不留 0 长度占位，见 series-template《川言川语》EP.01 一节。

## 渲染与后台进程

- 整片渲染前确认可用空间至少是预计成片体积的 3 倍，最后的 faststart 还会再拷一份。最后几帧报
  `Conversion failed` 时先怀疑磁盘（观测实例：exit 228，剩余 3.9 GB）；失败后先清 `TMPDIR` 下
  `remotion-*-assets*` 残留再重跑。
- 后台等待渲染或转写结束时记录 PID，用 `kill -0 PID` 轮询；不要用 `pgrep -f "命令片段"`，等待脚本自己的
  命令行也含这串字，会一直匹配到自己空转。

## 生成脚本

- 用脚本批量修改剪辑表或生成器时，每处替换先断言锚点恰好出现一次再替换；改动写成从上一版派生、可以整体
  重放的补丁脚本，不直接改生成物。任一断言失败整批不写入，并明确报告哪些改动没生效。观测实例：`str.index`
  定位到空串，把生成器写坏成 7 MB；另一次断言写在了错误的文件上，AssertionError 后整批未写入，下一步才发现。

## ASR

- Whisper 的 `initial_prompt` 只放风格句和专名词表，绝不放预期内容；否则没有人声的窗口会把提示原样当成
  转写结果（观测实例：三个不同时刻都“听到”了同一句预期原话）。
- 即使给了简体提示，长素材后段也会漂回繁体；输出后统一做一次繁转简。短片段随机出繁体的问题见
  [`audio-mix.md`](audio-mix.md)「客观门禁」下的可懂度说明。
- “谢谢观看”“订阅”“字幕 by”以及英文的 comments 套话这类片尾幻听，用正则标出来，交给审片页折叠或字幕过滤。

## 找回原图

- 作者直接贴进当前会话的图片没有文件路径，会话里的版本通常是降采样的：用文章里的嵌图文件名、编辑器的本地
  图片缓存目录，结合系统索引搜索找原图。只按修改时间搜最近几天可能找不到（观测实例：搜了三天没找到，改用
  嵌图文件名反查才找到）。

## 打码

- 手持镜头里的车牌用含车尾特征（尾灯）的多尺度模板匹配跟踪，不只靠颜色：蓝底车牌与天空的 HSV 分布重叠，
  颜色跟踪会被天空吸走。遮挡后在重新出现的时间点补种子（x, y, w, h @ t）分段重新锚定；打完每隔几帧放大
  核对一次，并把种子写进镜头配置，重渲时自动生效。
- 短暂出现、裁不掉的收款码或二维码，按源素材时间窗加模糊（例如 `gblur` 配合 `enable='between(t,…)'`），
  时间窗要覆盖叠化尾巴；参数写进镜头配置，复核工具和正式渲染共用同一份。
